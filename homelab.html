workflow
Coding on Debian Server VM — Projects are developed inside the Debian Server VM on VMware. Code is edited remotely from the phone via Acode SFTP — no need to touch the laptop directly.
Server Management via SSH — The Debian server is fully controlled through SSH on Termux, giving complete terminal access from the phone over Tailscale from anywhere.
Active Directory Lab — Windows Server Core 2022 and Windows 8.1 VMs are used exclusively for practicing and studying Active Directory administration.
Mobile Pentesting Rig — The Redmi Note 9S runs a full proot Debian environment with LEMP stack and DVWA for hands-on cybersecurity practice anywhere, anytime.
